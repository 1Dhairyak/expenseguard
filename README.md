# ExpenseGuard 💰🛡️

ExpenseGuard is a full-stack expense tracking and budgeting application designed to help users manage their finances efficiently through smart analytics, budget monitoring, and real-time expense tracking.

---

## 🚀 Features

### 🔐 Authentication & Security
- User Registration & Login
- JWT-based Authentication
- Protected APIs & Routes

### 💵 Expense Management
- Add Expenses & Income
- Edit/Delete Transactions
- Category-based Expense Tracking
- Real-time Balance Calculation

### 📊 Analytics Dashboard
- Monthly & Weekly Expense Reports
- Interactive Charts & Graphs
- Spending Analysis by Category
- Financial Insights

### 🎯 Budget Tracking
- Set Monthly Budgets
- Track Spending Limits
- Overspending Alerts

---
